# 博客平台功能梳理

## 用户体系

- **注册/登录/登出** — 邮箱或手机号注册，JWT/Token 认证
- **个人信息管理** — 头像、昵称、简介、社交链接
- **密码修改/忘记密码** — 邮箱验证重置
- **角色权限** — 普通用户、管理员、编辑

## 博客内容

- **文章管理** — CRUD（创建、编辑、删除、发布、草稿）
- **分类/标签** — 文章分类、标签云
- **文章详情页** — Markdown 渲染、代码高亮、目录导航
- **评论系统** — 文章评论、回复、点赞
- **搜索** — 全文搜索、标签筛选、分类筛选
- **置顶/推荐** — 首页推荐文章、编辑推荐

## 仪表盘

- **数据统计** — 文章数、访问量、点赞数、评论数
- **草稿管理** — 未发布的草稿列表
- **评论管理** — 查看/删除/回复评论
- **访问分析** — 日活、PV、热门文章

## 社交互动

- **关注/粉丝** — 用户关注关系
- **点赞/收藏** — 文章互动
- **分享** — 微信、微博分享
- **消息通知** — 评论回复、系统通知

## 后台管理

- **用户管理** — 用户列表、禁用/启用
- **内容审核** — 文章审核、违规内容处理
- **分类/标签管理** — 增删改查
- **站点配置** — SEO 设置、公告管理

## 技术支撑

- **文件上传** — 图片/附件上传（OSS/CDN）
- **Markdown 编辑器** — 实时预览、图片粘贴
- **缓存策略** — 静态资源缓存、CDN
- **SEO 优化** — Sitemap、Meta 标签、Open Graph
